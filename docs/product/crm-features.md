# お客様管理 — 機能一覧

> 本ドキュメントは **Fress CRM Template**（marmelab/atomic-crm ベース）の、現時点で利用できる機能をまとめたものです。  
> 画面に表示される名称は、日本語カスタム（`src/custom/`）に合わせています。  
> 最終更新: 2026-06-07

---

## 概要

**お客様管理** は、担当者・取引先企業・商談・メモ・タスクを一か所で扱う CRM です。

| 項目 | 内容 |
|------|------|
| 対象ユーザー | 中小企業・個人事業主の営業・事務担当 |
| 利用形態 | ブラウザ（PC）／スマホ（PWA） |
| データ保存 | Supabase（PostgreSQL） |
| 画面の既定言語 | 日本語（英語も選択可） |
| 業務上のタイムゾーン | 日本時間（JST）で日付を表示・入力 |

---

## 利用者の種類と権限

| 種類 | できること | できないこと |
|------|-----------|-------------|
| **管理者** | 上記すべて + **設定**の変更 + **利用者**の登録・管理 | 自分自身の管理者権限解除・利用停止 |
| **一般利用者** | 担当者・企業・商談・メモ・タスク・ラベルなどの日常業務 | **設定**・**利用者**メニュー |

### 初回セットアップ

1. システム未初期化時 → **利用者登録**（最初の1人のみ。自動的に管理者）
2. 担当者・メモがまだない間 → トップ画面に **初期設定ガイド（3ステップ）** を表示
3. データ投入後 → 通常のトップ画面へ

2人目以降の登録は、管理者が **利用者** 画面から行います。

## 画面別の機能

### ログイン・認証

| 機能 | 説明 |
|------|------|
| ログイン | メールアドレスとパスワード |
| 利用者登録 | 初回のみ（管理者となる方） |
| パスワード再設定 | メールで手順を送信 |
| Googleアカウントでログイン | 環境変数で有効化した場合のみ |
| メール確認 | 本番環境では初回登録後に確認メール |

### トップ画面（ダッシュボード）

#### 初期設定ガイド（データが少ないとき）

- **お客様管理の初期設定**（3ステップ）
  1. 初期設定完了
  2. **最初の担当者を登録**（手入力 or **CSVファイルを取り込む**）
  3. **最初のメモを書く**

#### 通常表示（PC）

| エリア | 内容 |
|--------|------|
| 左 | **有力なお客様** — 自分が担当で、見込みが **有力** の担当者（最大10件） |
| 中央上 | **今後の売上予定** — 直近6ヶ月の商談金額グラフ |
| 中央下 | **最近の動き** — 企業・担当者・メモ・商談の追加履歴 |
| 右 | **これからのタスク** — 自分の未完了タスク |

デモモード（`VITE_IS_DEMO=true`）のときのみ、英語の説明カードが表示されます。

#### 通常表示（スマホ）

- **最近の動き** のみ（有力なお客様・売上グラフ・タスク一覧は非表示）

---

### 担当者

**一覧（PC）**

- 並べ替え：名・姓・最後に連絡した日
- **書き出す** / **CSVファイルを取り込む** / **新しい担当者**
- 絞り込み例：
  - 最後に連絡した日（今日・今週・今月より前 など）
  - **お客様の見込み**（見込み薄い / 検討中 / 有力 / 契約中）
  - **ラベル**、**タスク**（未完了がある）、担当の営業
- 複数選択 → **ラベルを付ける** / 書き出す / 削除

**詳細**

- **メモ**・**タスク**・**詳しい内容**
- **メモを書く**、**タスクを追加**
- **連絡先ファイルに書き出す**（vCard）
- **別の担当者とまとめる**（2人分のデータを1人に統合。元に戻せません）

**お客様の見込み（4段階）**

| 表示名 | 意味の目安 |
|--------|-----------|
| 見込み薄い | まだ関心が低い |
| 検討中 | 提案・検討の段階 |
| 有力 | 積極的に追う見込み客 |
| 契約中 | 契約済み・取引中 |

メモに付けた見込みが、担当者の状態として反映されます。

---

### 取引先企業

- 一覧・登録・修正・詳細
- 企業名、住所、業種、従業員規模、売上、担当の営業 など
- 詳細から紐づく担当者・商談・**最近の動き**を確認

**スマホ**: 企業の一覧画面はなく、詳細画面のみ（担当者などから遷移）

---

### 商談（PC のみ）

カンバン形式のパイプラインで商談を管理します。

**既定の段階**

| 段階 | 説明の目安 |
|------|-----------|
| 新規案件 | 案件が発生した |
| 見積もり送付済み | 見積を送った |
| 交渉中 | 条件を詰めている |
| 成約 | 受注した |
| 失注 | 失注した |
| 保留 | 時期を先送り |

- ドラッグ＆ドロップで段階変更
- **保管する** / **保管した商談を見る** で一覧から外して保管
- 商談メモ、担当者、金額、成約予定日

**スマホ**: 商談画面は利用できません

---

### メモ

- 担当者または商談に紐づく
- **メモを書く** / **メモを直す** / **メモを削除**
- **お客様の見込み**、日付、**ファイルを添付**
- 日付は **日本時間** で表示（例：昨日 午後2:30）

---

### タスク

- **内容**・**期限**・**種類**（メール・打ち合わせ・電話 など）・担当者
- 期限別表示：期限超過 / 今日 / 明日 / 今週 / あとで
- **明日にずらす** / **来週にずらす**

---

### ラベル

- 担当者に色付きの **ラベル** を付けて分類
- 一覧から複数人を選び **ラベルを付ける**（一括）

---

### 利用者（管理者のみ）

- **新しい利用者** を登録 → パスワード設定メールが届く
- 管理者フラグ・**利用停止** の変更
- 自分自身の権限は変更不可

---

### 個人設定

| 項目 | 内容 |
|------|------|
| 個人設定 | 名前・メール・アバター |
| 表示する言語 | 日本語 / English |
| パスワードを変更 | 再設定メールを送信 |
| メールでメモを登録 | 専用メールアドレス（設定時のみ表示） |
| 他のソフトとの連携 | MCP 用 URL（AI アシスタント連携） |

---

### 設定（管理者・PC のみ）

| セクション | 変更できる内容 |
|-----------|---------------|
| 名称とロゴ | **画面のタイトル**、明るい／暗い画面用ロゴ |
| 取引先企業 | **業種** の一覧 |
| 商談 | **通貨**、**商談の段階**、トップに表示する段階、**商談の種類** |
| メモ | **お客様の見込み**（名前と色） |
| タスク | **タスクの種類** |

- **最初の設定に戻す** で既定値に復元（Fress 既定は日本語ラベル）
- 商談で使われている段階・種類は削除できません

**スマホの設定画面**: 個人設定・表示の設定・更新のお知らせのみ（CRM 全体の設定は不可）

---

### データの取り込み

| 方式 | 対象 | 入口 |
|------|------|------|
| CSV | 担当者（企業・ラベルも自動作成） | 担当者一覧 |
| JSON | 利用者・企業・担当者・メモ・タスク | ユーザーメニュー → **データを取り込む** |

取り込み中は画面を移動しないでください。エラーがある場合は **エラー一覧をダウンロード** できます。

---

### 書き出し

| 方式 | 対象 |
|------|------|
| CSV | 担当者・取引先企業・商談・利用者（各一覧の **書き出す**） |
| vCard | 担当者1件（詳細の **連絡先ファイルに書き出す**） |

---

### 更新のお知らせ

- `CHANGELOG.md` の内容をアプリ内で表示
- PC: ユーザーメニュー / スマホ: 設定 → **この画面について**

## 連携機能（要サーバー設定）

### メールでメモを登録

- 専用の受信メールアドレスに送信すると、該当担当者のメモとして登録
- 個人設定にアドレスが表示される（`VITE_INBOUND_EMAIL` 設定時）
- 詳細なサーバー設定: 上流ドキュメント `doc/src/content/docs/developers/inbound-email-configuration.mdx`

### 他のソフトとの連携（MCP）

- AI アシスタントなどから CRM データを参照・操作
- 個人設定に連携用 URL を表示
- 詳細: `doc/src/content/docs/users/mcp-server.mdx`

## 制限・注意事項

| 項目 | 内容 |

| 自己登録 | 最初の1ユーザーのみ |
