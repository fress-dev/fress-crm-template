## Salus → CRM マッピング早見表


| Salus             | CRM 候補               | 層の候補              | 備考                  |
| ----------------- | -------------------- | ----------------- | ------------------- |
| `User`（会員）        | `contacts`           | **コア**            | 氏名・連絡先・ラベルで足りる部分が多い |
| `Trainer`         | `sales`              | **コア**            | スタッフ＝CRM 利用者        |
| `Store` / `Room`  | `plugin-stores` 等   | **プラグイン**         | noexcuse は船橋店・千葉店等（[plugin-stores.md](../design/archive/plugin-stores.md)） |
| `Course`          | Product / Plan       | **プラグイン**         | コース種別・時間            |
| `Contract`        | Deal 拡張 or Contract  | **要判断**           | 金額なし・回数券モデル         |
| `Ticket`          | Entitlement / Credit | **プラグイン**         | コアに相当なし             |
| `Schedule`        | Appointment（未実施）     | **プラグイン**         | カウンセリング等            |
| `Session`         | Visit + 身体データ        | **プラグイン**         | 予約と実施が一体            |
| `TrainingContent` | Activity line items  | **プラグイン**         | 種目・セット記録            |
| 身体グラフ             | Dashboard / Chart    | **プラグイン or カスタム** |                     |
| スケジュールコピー         | メモテンプレ               | **カスタム層**         | 手動 LINE 等           |
| 決済                | —                    | **Salus にも無し**    | 将来連携プラグイン           |

## フェーズ別の切り分け案（確認用）

### A. コア＋テナント設定（コード最小）で始められる範囲


| Salus 機能 | CRM での表現                | 十分か           |
| -------- | ----------------------- | ------------- |
| 会員マスタ    | Contact + ラベル           | ○ 基本情報は足りる    |
| トレーナー    | sales                   | ○             |
| 体験〜入会    | Deal パイプライン（段階名をジム用に変更） | △ 金額・回数は別管理   |
| フォロー     | Task                    | ○             |
| 簡易メモ     | contact_notes           | △ 身体データ・種目は無理 |
| 会員区分     | tags                    | ○             |


**論点（ご確認ください）:**

- [ ] 商談（Deal）を「入会パイプライン」として使うか（体験 / 検討 / 入会 / 離脱）
- [ ] 取引先企業（companies）は **無効化・非表示** でよいか
- [ ] 商談の「金額」フィールドは **未使用** でよいか（Salus に決済がないため）

---

### B. プラグインが必要な範囲（Salus の中核）

優先度の高い順:


| 優先     | 機能                    | 理由                          |
| ------ | --------------------- | --------------------------- |
| **P0** | 予約・カレンダー              | Salus の日常業務の中心（`/schedule`） |
| **P0** | 契約・チケット（回数券）          | セッション消費の前提                  |
| **P1** | セッション記録（身体データ）        | カルテの価値の大半                   |
| **P1** | コースマスタ                | 契約の前提                       |
| **P0** | 店舗マスタ（`plugin-stores`）   | noexcuse 複数店舗。会員・予約の前提        |
| **P2** | 部屋                      | 予約プラグインと同時検討                 |
| **P2** | 店舗権限（RLS）               | スタッフは担当店舗のみ閲覧・編集（Phase 2）   |
| **P2** | 種目マスタ・TrainingContent | トレーニング記録                    |
| **P3** | 一括予約                  | 運用効率（後回し可）                  |
| **P3** | 身体グラフ                 | 可視化（後回し可）                   |


**論点:**

- [ ] P0 を **1プラグイン（例: `plugin-gym-core`）** にまとめるか、**機能単位で分割**（`appointments` + `memberships` 等）するか  
  → [plugin-architecture.md](../../architecture/plugin-architecture.md) は **機能単位分割を優先**
- [ ] 最初の1本は何から始めるか（予約 only / 契約+チケット only / 縦切り1本）

---

### C. Salus にあっても CRM で不要な可能性があるもの


| 機能               | 不要になりうる理由    | ご確認 |
| ---------------- | ------------ | --- |
| 取引先企業            | 個人ジム・B2C     | [ ] |
| 商談金額・売上グラフ       | 回数券モデルと合わない  | [ ] |
| 会員ログイン           | Salus にも無かった | [ ] |
| API（Sanctum スタブ） | 未使用          | [ ] |
| `companies` リソース | コアにあるが使わない   | [ ] |

### D. Salus に無く CRM で検討できるもの


| CRM 機能         | ジムで使うか       |
| -------------- | ------------ |
| インバウンドメール → メモ | 問い合わせメール取り込み |
| MCP 連携         | AI / 外部ツール連携 |
| CSV 入出力        | 会員データ移行      |
| PWA モバイル       | 現場からの閲覧      |

## 推奨する進め方（3ステップ）

```
Step 1（今）     research/ を人間が確認 ← いまここ
Step 2（次）     コアで足りる範囲をテナント設定案に落とす（段階名・ラベル・タスク種類）
Step 3（その後）  P0 プラグインを design/ に1本ずつ（1 PR = 1 設計書）
```

### Step 2 で決めること（テナント設定・管理画面）


| 項目    | Salus 相当 | CRM 設定案の例                 |
| ----- | -------- | ------------------------- |
| 商談段階  | 体験〜入会    | 体験予約 / 体験済 / 検討 / 入会 / 離脱 |
| ラベル   | コース区分    | 月4回 / 月8回 / 都度 / 休会       |
| タスク種類 | フォロー     | 体験後連絡 / 更新案内 / 休会フォロー     |
| 見込み   | 会員ステータス  | 見込み / 契約中 / 休会            |


※ 初回テナント `tenants/noexcuse.json`（タイトル: **noexcuse CRM**）。店舗マスタは別プラグイン

### Step 3 のプラグイン分割案（機能単位）


| 設計書（案）                | スコープ           | Salus 対応                        |
| --------------------- | -------------- | ------------------------------- |
| `plugin-stores`       | 店舗マスタ・会員の在籍店舗  | Store, `users.store_id`         |
| `plugin-appointments` | 予約・カレンダー・部屋    | Schedule, ScheduleBulk          |
| `plugin-memberships`  | コース・契約・チケット    | Course, Contract, Ticket        |
| `plugin-session-log`  | セッション記録・身体・種目  | Session, TrainingContent, Graph |
